# 功能清单与分期

> 九大需求区域映射；**【假设】合同可按 MVP / 二期分期验收**。验收要点为草图，细节以 `04` 为准。

---

## 1. 分期总览

| 分期 | 目标 | 包含 |
|------|------|------|
| **MVP（一期）** | 能收数、能告警闭环、能采摘清单与 Excel、能管设备与权限 | 接入、告警、采摘/报表、设备档案、RBAC、管理端可用、大屏基础总览 |
| **二期** | 精装指挥体验与分析增强 | 精装大屏/抓拍墙、生长趋势、病害—环境联动溯源、2–3 日产量预估、企微/钉钉推送 |

> **【假设】日历说明（内部）**：能力按 **MVP / 二期** 分期即可；内部实施为 coding agent 加速的 **Day-scale**（Day-1 架构地基起），招标方文档可不写具体工期天数（若原文未写）。详见仓库 `docs/项目计划书.md`。

## 2. 九大需求 × 功能映射

### R1 数据接入（MQTT / HTTP）

| 功能项 | 分期 | 验收要点草图 |
|--------|------|--------------|
| MQTT 订阅既有 Topic，落库识别结果 | MVP | 按冻结样例报文连续接收 ≥24h，丢包率可统计 |
| HTTP 上报与断网补传接口 | MVP | 补传幂等，重复键不双计 |
| Schema 校验、去重、异常过滤 | MVP | 非法报文拒收并记日志；可查拒收原因 |
| 抓拍图写入对象存储并按棚/日/摄像头归档 | MVP | 路径可检索；缩略图可在管理端打开 |

### R2 看板 / 指挥大屏

| 功能项 | 分期 | 验收要点草图 |
|--------|------|--------------|
| 管理端：基地/棚汇总（数量、成熟、病害、在线） | MVP | 授权棚数据正确隔离 |
| 指挥大屏：清亮农作物风格总览 + 告警条 + 基础抓拍区（暗色非必须） | MVP | 1080p 可投屏；风格符合 `05`；非公安/雪亮类比 |
| 棚区平面示意（非真 3D） | MVP | 点击棚可下钻摘要 |
| 精装大屏：抓拍墙、多屏布局、对比时间轴入口 | 二期 | 按演示脚本走通 |

### R3 告警（阈值 + 三级 + 闭环 + 推送）

| 功能项 | 分期 | 验收要点草图 |
|--------|------|--------------|
| 阈值可配（成熟、病害、生长停滞、环境、离线） | MVP | 改阈后新数据按新规则 |
| 三级：提示 / 一般 / 严重 | MVP | 列表与大屏颜色区分 |
| 闭环：确认/认领 → 处置备注 → 关闭/误报 | MVP | 全链路可审计 |
| 站内消息 + 浏览器通知 | MVP | 严重级可触发浏览器通知（需授权） |
| 企微 / 钉钉推送 | 二期 | 按客户机器人配置打通 |

**【假设】默认阈值（可后台改）**

| 类型 | 提示 | 一般 | 严重 |
|------|------|------|------|
| 单路成熟占比 | ≥40% | ≥60% | ≥80% |
| 单路病害数量 | ≥1 | ≥3 | ≥5 或高等级病害 |
| 环境温度偏离设定 | ±1℃ | ±2℃ | ±3℃ |
| 环境湿度偏离设定 | ±5% | ±10% | ±15% |
| CO₂ | 超上限 10% | 20% | 30% |
| 设备离线 | 心跳缺 2 周期 | 缺 5 周期 | 缺 15 分钟以上 |
| 生长停滞 | — | 连续 48h 直径无增长 | 连续 72h |

（设定中心值由棚档案配置；**【假设】样本中心：温度 18℃、湿度 85%、CO₂ 上限 1200ppm。**)

## 3. MVP 验收包（建议）

1. 按样例报文接入成功，管理端可见近实时数据与抓拍。  
2. 触发至少 3 类告警，完成闭环与审计查询。  
3. 导出至少 2 类 Excel；生成当日采摘清单。  
4. 110 路级设备档案可维护；四角色权限演示通过。  
5. 指挥大屏基础页可投屏演示（平面棚图 + 告警 + 汇总；清亮农作物监控风格为主，暗色非必须）。

## 4. 二期验收包（建议）

1. 精装大屏/抓拍墙演示脚本通过。  
2. 生长趋势与病害—环境联动可复盘。  
3. 产量预估在历史门槛满足后给出 2–3 日估计并说明误差口径。  
4. 企微或钉钉任选一通道推送严重告警成功。
