# 界面与交付说明

> 约束「可投屏农业监控大屏」的交付预期。视觉以**清亮农作物监控风格**为主，暗色非必须。  
> 避免像素级对标与知识产权纠纷，也避免把本产品写成公安 / 雪亮类公共安全视频监控。  
> 与 `04-招标技术规格书草稿.md` 第 7 章配套，建议作为招标附件。

---

## 1. UI 承诺边界（写给验收）

| 承诺 | 不承诺 |
|------|--------|
| 清亮农作物监控风格指挥大屏，信息密度适合基地值班/投屏（暗色仅可选，不是验收项） | 像素级复刻某厂商或某效果图的每一个控件位置 |
| 农业监控取向：明亮底、棚区与作物状态色、卡片化指标、告警醒目 | 公安 / 雪亮或任何公共安全指挥中心类比；把暗色底写成硬性要求 |
| 棚区**平面示意 / 拓扑图**可点击下钻 | 真三维 GIS、倾斜摄影、数字孪生机房级建模 |
| 管理端与大屏同一设计语言，组件整齐、中文可读 | 「概念稿级」不可交互静态图作为最终交付；使用或仿冒任何第三方商标、Logo、未授权切图 |
| MVP 即具备可投屏基础总览页（清亮可为主，暗色非必须） | 二期精装动效/多布局未采购却强制一期交齐 |

**硬约束一句话**：交付物须达到**可对外演示的产品级农业监控界面**（含可投屏大屏），而不是默认主题管理后台 + 口头承诺「以后再做大屏」。暗色不是硬约束，公安 / 雪亮类比不是验收口径。

## 2. 风格参照（行业取向，非知识产权主张）

以下仅作**风格与信息架构参照**，投标人与实施方**不得**声称拥有这些厂商的 UI/品牌权益，也不得在交付物中出现其商标：

| 参照类型 | 取向说明 |
|----------|----------|
| 环控云 + 大屏类（如建大仁科等产品常见形态） | 环境指标卡片、曲线、棚列表与告警 |
| 工业 HMI 类（如圣启洛阳等常见形态） | 状态色、设备在线、参数面板清晰 |
| 工厂化农业案例（如成都丰科 / 华为等公开案例常见形态） | 总览指挥感、多数据源汇聚 |

**明确不作为参照**：公安 / 雪亮及同类公共安全视频监控指挥中心。该说法来自早期头脑风暴，不是本产品定位，也不得写入验收。

**本项目差异化卖点（界面上须能看出来）**：在环控与指挥大屏之上，突出 **AI 数菇结果汇聚 + 抓拍墙/抓拍检索**（识别本身仍在边缘，平台做汇聚展示）。

## 3. 页面与模块（界面清单）

### 3.1 管理端（MVP 必须可操作）

- 登录页（清亮农业风或统一品牌条均可，须专业；不强制暗色）  
- 基地总览、棚详情  
- 实时/近实时识别结果与抓拍浏览  
- 告警列表与处置单  
- 采摘清单  
- 设备档案（摄像头 / AI 盒 / 传感器）  
- 用户角色与棚授权  
- 报表导出入口  
- 审计日志查询  

### 3.2 指挥大屏（MVP 必须可投屏）

| 区块 | MVP | 二期增强 |
|------|:---:|:--------:|
| 顶部标题 + 时钟 + 基地名称 | ● | — |
| 关键指标（棚数、在线摄像头、今日识别、未关闭告警） | ● | 动效/多主题 |
| 棚平面 / 拓扑示意 + 状态色 | ● | 更细粒度动画 |
| 告警滚动 / 告警列表 | ● | 分级声光策略（可选） |
| 基础抓拍区（最新 N 张） | ● | **抓拍墙**多路宫格 |
| 环境雷达/曲线小组件 | △ 有数据即展示 | 多棚对比 |
| 对比时间轴 | — | ● |

**【假设】MVP 大屏默认布局**：顶栏指标 + 左平面示意 + 右告警 + 底/侧抓拍条；分辨率按 1920×1080 设计。

## 4. 演示范围（验收演示脚本建议）

1. **登录**：超管进入管理端；另用棚区负责人账号证明隔离。  
2. **模拟上报**：注入样例识别结果（含病害与抓拍），总览数字变化。  
3. **告警闭环**：触发严重告警 → 大屏可见 → 管理端确认处置 → 关闭。  
4. **采摘与导出**：打开当日可采 → 导出一类 Excel。  
5. **大屏投屏**：浏览器全屏 1080p，讲解平面棚图与抓拍区（不演示真 3D）。  
6. **（二期）** 抓拍墙、趋势、预估、企微/钉钉择一。

演示数据允许使用模拟器；须与冻结字段一致。

## 6. 验收否决与澄清

**可判定未达 UI 硬约束的情形：**

- 仅交付默认组件库皮肤后台，无可投屏的农业监控大屏页。  
- 大屏为单张无法交互的海报图。  
- 界面出现未授权的第三方品牌标识。  
- 以「未采购三维引擎」为由拒绝提供平面态势总览。

**可澄清、不作为否决的情形：**

- 图标风格、圆角、字体与某张概念图不完全一致。  
- 二期抓拍墙未在一期合同范围内。  
- 平面棚图为示意而非测绘级 CAD 精度（**【假设】允许 SVG/配置化热区**）。
