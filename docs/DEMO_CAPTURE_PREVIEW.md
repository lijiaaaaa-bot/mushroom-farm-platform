# 抓拍对照可查可见

先把数据库和前后端跑起来（已经在跑就跳过）。三个终端：

```bash
make up && make migrate
make api
make web
```

API 监听 http://127.0.0.1:41821 。页面是 http://127.0.0.1:43123 。

在仓库根目录：

```bash
make demo-capture-preview
```

命令读取 `packages/contracts/fixtures/recognition.demo-one.json`，只作报文底稿。样例文件不改。写入摄像头 `CAM-CP-01`、棚区 `S01` 的三条识别，识别时间各不相同，每条都带可打开的抓拍：

| 相对运行时刻 | 蘑菇数 | 成熟 | 病害 |
| --- | --- | --- | --- |
| 前 20 分钟 | 8 | 2 | 1 |
| 前 10 分钟 | 10 | 4 | 1 |
| 当前 | 12 | 5 | 1 |

病害等级 1。温度 22.5℃，湿度 88%，CO₂ 900，基质含水率 70%。成熟占比低于种子规则「成熟占比一般」的 0.6。病害数量低于「病害数量一般」的 5。病害等级低于「病害等级一般」的 2。幂等键带本次毫秒，再跑会再写三条。样例里的 `CAM-DEMO-01`、蘑菇数 12、病害数量 1 不改。对象存储没起来时，写入失败。

然后读两份识别列表，窗口是运行时刻前 25 分钟到后 1 分钟：

- `GET /api/v1/ingest/recognitions?shedCode=S01&cameraCode=CAM-CP-01&from=&to=` 里有这三条，蘑菇数 8、10、12，每条 `snapshotObjectKey` 有值，`GET /api/v1/ingest/recognitions/:id/snapshot` 读回的字节与样例 JPEG 一致。
- 同一窗口 `cameraCode=CAM-CP-NONE` 的列表是空的。

终端打印这两个地址：

```text
打开: http://127.0.0.1:43123/capture-preview?shedCode=S01&cameraCode=CAM-CP-01&from=...&to=...
对照: http://127.0.0.1:43123/capture-preview?shedCode=S01&cameraCode=CAM-CP-NONE&from=...&to=...
```

浏览器打开 http://127.0.0.1:43123/login ，账号 `admin`，密码 `Admin@123456`。侧栏「抓拍对照」也进这一页。

## 1. 同一屏对照原始图和标注

打开终端里的「打开」。页上能读到：

| 位置 | 值 |
| --- | --- |
| 标题 | 抓拍对照 |
| 棚区 | S01 |
| 摄像头 | CAM-CP-01 |
| 旁注 | 原始 · 标注 · 时间轴 3 点 |
| 左 | 原始，一张抓拍图 |
| 右 | 标注，同一张图上有「AI标注」「蘑菇数 12」「成熟 5」「病害 1」 |
| 下方 | 历史时间轴 3 条，蘑菇数 12、10、8 |

点时间轴上蘑菇数 8 的那一条，右边换成「蘑菇数 8」「成熟 2」「病害 1」。左右仍是同一屏。

窗口里若已有这台摄像头更早的抓拍，时间轴点数会多于 3。终端打印的起止时间只包住这一次的三条时，页上是「时间轴 3 点」。

## 2. 对照

打开终端里的「对照」。摄像头是 `CAM-CP-NONE`。页面写「没有可回看的抓拍。」没有左右两张图。

一条识别没有抓拍对象键时，左边写「无原始抓拍」，右边写「无标注图」。这次写入的三条都有图，打开地址上看不到这两句。

## 验收

- `make demo-capture-preview` 在 API 已启动、对象存储可写时退出码 0，并打印打开和对照两个地址。终端里能读到「原始」「标注」和「时间轴 3 点」。
- 打开截图同一屏左边是原始抓拍，右边是 AI标注，下方时间轴有 3 条不同时间。
- 对照截图文案含「没有可回看的抓拍。」

这一页读已有识别列表和抓拍。`/recognitions` 仍是记录列表，不是这一页的左右对照。`/big-screen` 抓拍墙不改。`/shed-live-stats`、`/shed-growth-delta`、`/shed-disease-trend`、`/shed-env-24h`、病害高发、成熟率旁注不改。不改接入观测。不改样例文件。

本机若没有 Docker，或 API 没在 41821 监听，命令不会对接口实发。Mac 上再跑 `make demo-capture-preview`，并按上面的地址截图。
