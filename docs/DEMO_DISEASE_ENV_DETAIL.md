# 病害详情同屏环境可查可见

先把数据库和前后端跑起来（已经在跑就跳过）。三个终端：

```bash
make up && make migrate
make api
make web
```

API 监听 http://127.0.0.1:41821 。页面是 http://127.0.0.1:43123 。

在仓库根目录：

```bash
make demo-disease-env-detail
```

命令读两份样例，文件本身不改。

- `packages/contracts/fixtures/recognition.demo-one.json` 只改本次请求：摄像头 `CAM-DED-01`，棚区 S01，病害数量 2，病害等级 1，识别时间改成当前时刻，幂等键改成 `demo-disease-env-<毫秒>`。样例里的 `CAM-DEMO-01`、病害数量 1、温度 22.5℃ 不改。
- `packages/contracts/fixtures/environment.demo-disease-env-detail.json` 写入传感器 `SENSOR-DED-01`。观测时间按这次识别改，幂等键固定。同一键已在则改观测时间和这四个数，不另建一行。`environment.golden.json` 不改。

三条环境读数：

| 位置 | 观测时间 | 温度 | 湿度 | CO₂ | 基质含水率 |
| --- | --- | --- | --- | --- | --- |
| 窗内较早 | 识别前 8 分钟 | 23.8℃ | 84% | 640 | 73% |
| 窗内较近 | 识别前 2 分钟 | 24.1℃ | 86% | 710 | 75% |
| 窗外 | 识别前 3 小时 | 16.8℃ | 82% | 700 | 61% |

窗口是识别时间前后各 30 分钟（`DISEASE_ENV_WINDOW_MINUTES`）。前两行在窗内，16.8℃ 在窗外。

温度在 12℃ 和 28℃ 之间，湿度在 70% 和 98% 之间，CO₂ 低于 2000，基质含水率高于 50%。病害数量 2 低于种子规则「病害数量一般」的 5，病害等级 1 低于「病害等级一般」的 2。这条识别和这三条环境读数不新开告警。识别报文里的 22.5℃ 不写入环境读数，详情也不拿它充数。

抓拍要能从对象存储读回。对象存储没起来时命令失败。

然后读两份接口：

- `GET /api/v1/diseases/:id` 是这条病害。时间、棚区 S01、位置 `CAM-DED-01`、病害等级 1、病害数量 2，并且有抓拍。
- `GET /api/v1/diseases/:id/environment` 的读数里有 23.8℃ 和 24.1℃，湿度、CO₂、基质含水率与上表一致，并带观测时间。没有 16.8℃。

终端打印详情地址：

```text
病害详情: http://127.0.0.1:43123/diseases/<id>
```

浏览器打开 http://127.0.0.1:43123/login ，账号 `admin`，密码 `Admin@123456`。

## 1. 同一屏

打开终端里的「病害详情」。顶栏是「病害详情」。这一页同时能读到：

| 标签 | 值 |
| --- | --- |
| 时间 | 这次识别的上海时间 |
| 棚区 | S01 |
| 位置 | CAM-DED-01 |
| 病害等级 | 轻度（1） |
| 病害数量 | 2 |
| 病害图片 | 样例 JPEG |

下方「同期环境」表有两行，传感器都是 `SENSOR-DED-01`：

| 观测时间 | 温度 | 湿度 | CO₂ | 基质含水率 |
| --- | --- | --- | --- | --- |
| 识别前 8 分钟，上海时间到分钟 | 23.8℃ | 84% | 640 | 73% |
| 识别前 2 分钟，上海时间到分钟 | 24.1℃ | 86% | 710 | 75% |

两行的观测时间不是同一分钟。表里没有 16.8℃。同棚其他传感器若落在这 30 分钟里，也会出现在这张表；`SENSOR-DED-01` 仍是这两行。

没有这两行，或只看见病害、看不见温度，都算没对上。

## 2. 空窗

这次命令不另写一条没有环境读数的病害。窗内没有读数时，同一页仍写出病害字段，同期环境写「该时间窗内无环境读数」，不显示温度表，也不把识别报文里的 22.5℃ 填进表。

## 验收

- `make demo-disease-env-detail` 在 API 与对象存储已启动时退出码 0，并打印 `/diseases/<id>`。
- 详情页同一屏能读到病害字段，以及 23.8℃、24.1℃ 和对应的湿度、CO₂、基质含水率、观测时间。
- 16.8℃ 不在这一页的同期环境表里。
- 空窗文案是「该时间窗内无环境读数」。

`make demo-disease-list` 与 `make demo-disease-grade-filter` 不改。不改 `make demo-env-filter`、`make demo-telemetry-latest`、`make demo-telemetry-history`。不改接入观测。不改协议字段。
