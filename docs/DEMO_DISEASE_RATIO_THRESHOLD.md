# 病害比例、重度病害数量阈值与病害预警

先把数据库和前后端跑起来（已经在跑就跳过）。三个终端：

```bash
make up && make migrate
make api
make web
```

API 监听 http://127.0.0.1:41821 。页面是 http://127.0.0.1:43123 。

在仓库根目录：

```bash
make demo-disease-ratio-threshold
```

命令用管理员账号读写已有的阈值规则，不另建一套配置。没有名为「病害比例预警」、指标为病害比例、棚区为空（全场）的规则时，`POST /api/v1/alert-rules` 新建一条：级别提示，窗口 720 分钟，阈值 20。没有名为「重度病害预警」、指标为重度病害数量、棚区为空的规则时，同样新建一条，阈值 4。然后 `PATCH /api/v1/alert-rules/:id`，把两条都写成上述阈值并保持启用。同一指标上其他已启用的规则会改成停用，避免总览改读另一条更小的阈值。种子规则不改，包括「病害数量一般」仍是 5，「病害等级一般」仍是 2，「病害等级严重」仍是 3。

然后读取 `packages/contracts/fixtures/recognition.demo-one.json`，只作报文底稿。样例文件不改。写入当天两条识别，识别时间都在运行时刻的上海自然日里：

| 棚区 | 摄像头 | 蘑菇数 | 成熟 | 病害数量 | 病害等级 |
| --- | --- | --- | --- | --- | --- |
| `S01` | `CAM-DRT-01` | 20 | 4 | 4 | 3 |
| `S02` | `CAM-DRT-ZERO` | 0 | 0 | 0 | 0 |

温度 22.5℃，湿度 88%，CO₂ 900，基质含水率 70%。成熟占比 4/20，低于种子规则「成熟占比一般」的 0.6。病害数量低于「病害数量一般」的 5。病害等级 3 会达到「病害等级一般」和「病害等级严重」。幂等键是 `demo-disease-ratio-threshold-<摄像头>-<上海日>`。同一上海日再跑不另建一行。样例里的 `CAM-DEMO-01`、蘑菇数 12、病害数量 1、病害等级 1、AI抓拍图不改。本次请求不带抓拍。病害比例和重度病害数量这两条规则不按单条识别新开告警。写入后，命令只关闭 `CAM-DRT-01` 与 `CAM-DRT-ZERO` 上指标为病害等级的未闭合告警，备注「病害预警演示后关闭」。不关别的摄像头，不改认领。

然后读 `GET /api/v1/dashboard/overview`。两条阈值都是全场规则上的整数。当前比例是当日各棚摄像头日桶最新病害数之和 ÷ 蘑菇数之和，百分数保留一位，蘑菇为 0 时是 0。当前重度是当日各棚摄像头日桶 `disease_severe_count` 相加：该摄像头当天最新一条的病害等级为 3 时记下病害数量，否则是 0。棚级行不重复计入。当前比例 ≥ 20 或当前重度 ≥ 4 时，对应横幅出现。干净当天两条都达到。

终端第一行是比例横幅，第二行是重度横幅。干净的当天、没有别的病害或蘑菇日桶时：

```text
病害预警 比例≥20% 当前20%
病害预警 重度≥4 当前4
```

当天已有别的摄像头时，比例不小于 20、重度不小于 4，旁注变成「病害预警 比例≥20% 当前P%」和「病害预警 重度≥4 当前N」，仍然等于总览接口，也等于总览页上的横幅。

浏览器打开 http://127.0.0.1:43123/login ，账号 `admin`，密码 `Admin@123456`。

## 1. 总览

打开 http://127.0.0.1:43123/ 。采摘提醒下面有一块「病害预警」。病害比例阈值的输入框是 20，重度病害数量阈值的输入框是 4。配置旁注是「病害比例阈值 20% · 全场 · 当前比例 P% · 重度病害数量阈值 4 · 全场 · 当前重度 N」。两条都达到时，下面有两条横幅，文案与终端前两行相同。干净当天是「病害预警 比例≥20% 当前20%」和「病害预警 重度≥4 当前4」。超管和生产管理员可以改输入框并点「保存」，保存后重新读总览。查看角色看得到阈值，没有「保存」。没有这两类规则时，配置旁注是「尚未配置病害比例/重度阈值」，没有横幅。

`/alert-rules` 里这两条规则的指标是「病害比例」和「重度病害数量」，阈值是 20 和 4，棚区是全场，启用是「是」。总览这一块就是改这两条规则，不另存一份阈值。

## 2. 对照

`CAM-DRT-ZERO` 病害是 0、等级是 0，不把全场抬高。`CAM-DRT-NONE` 当天没有识别。干净的当天、没有别的病害或蘑菇日桶时，横幅是上面两句。再跑一次仍是这个旁注。

## Mac 截图验收

在 Mac 上 API 已监听 41821、页面已打开时：

1. 跑 `make demo-disease-ratio-threshold`。终端前两行与总览两条横幅相同。
2. 截总览 `/`：标题是「病害预警」，比例输入框能读到 20，重度输入框能读到 4，横幅能读到「病害预警 比例≥20% 当前P%」和「病害预警 重度≥4 当前N」。干净当天 P 是 20，N 是 4。
3. 配置旁注能读到「病害比例阈值 20% · 全场 · 当前比例 P% · 重度病害数量阈值 4 · 全场 · 当前重度 N」，P 和 N 与横幅里的当前数相同。

## 验收

- `make demo-disease-ratio-threshold` 在 API 已启动时退出码 0。终端第一行是「病害预警 比例≥20% 当前P%」，第二行是「病害预警 重度≥4 当前N」。干净当天 P 是 20，N 是 4。当前比例不小于 20，当前重度不小于 4。
- 总览 `/` 上的两个阈值、配置旁注和两条横幅与这一输出相同。
- `GET /api/v1/dashboard/overview` 的 `diseaseWarnRatioThreshold` 是 20，`diseaseWarnRatioActive` 是 true，`diseaseWarnRatioPercent` 是 P，`diseaseWarnRatioNote` 是「病害预警 比例≥20% 当前P%」，`diseaseWarnRatioShedCode` 是空。`diseaseWarnSevereThreshold` 是 4，`diseaseWarnSevereActive` 是 true，`diseaseWarnSevereCount` 是 N，`diseaseWarnSevereNote` 是「病害预警 重度≥4 当前N」，`diseaseWarnSevereShedCode` 是空。
- 对照摄像头 `CAM-DRT-NONE` 当天是 0 条。`CAM-DRT-ZERO` 蘑菇 0、病害 0、等级 0。`CAM-DRT-01` 蘑菇 20、病害 4、等级 3。
- 这两台摄像头上没有指标为病害比例或重度病害数量的待确认告警。种子病害等级告警已关闭。

不改采摘提醒、在养蘑菇总数、当日病害总数、今日识别次数、今日抓拍总量、全园环境参数均值、异常环境点位数、全局设备在线的旁注。不改基地大屏。不改接入观测。不改样例文件。不改病害详情同期环境，不改告警认领。不画点位分布。

本机若没有 Docker，或 API 没在 41821 监听，命令不会对接口实发。Mac 上再跑 `make demo-disease-ratio-threshold`，并按上面的地址截图。
