# 全园环境参数均值

先把数据库和前后端跑起来（已经在跑就跳过）。三个终端：

```bash
make up && make migrate
make api
make web
```

API 监听 http://127.0.0.1:41821 。页面是 http://127.0.0.1:43123 。

在仓库根目录：

```bash
make demo-env-mean
```

命令读取 `packages/contracts/fixtures/environment.demo-history.json`，只作报文底稿。样例文件不改。写入当天两台传感器，观测时间都在运行时刻的上海自然日里：

| 棚区 | 传感器 | 温度 | 湿度 | CO₂ | 基质含水率 |
| --- | --- | --- | --- | --- | --- |
| `S01` | `SENSOR-EM-01` | 22℃ | 78% | 620 | 68% |
| `S02` | `SENSOR-EM-02` | 26℃ | 92% | 980 | 78% |

另写昨天一台 `SENSOR-EM-YDAY`（棚区 `S01`）：16℃ / 80% / CO₂ 500 / 基质含水率 60%。它不进今天的均值。对照 `SENSOR-EM-NONE` 不写入。

四个数都躲开种子规则：温度在 12 和 28 之间，湿度在 70 和 98 之间，CO₂ 低于 2000，基质含水率高于 50。幂等键是 `demo-env-mean-<传感器>-<上海日>`。同一上海日再跑不另建一行，并重写这台传感器当天的日桶。样例里的 `SENSOR-HIST-01`、温度 23.1 不改。

然后读当天的环境列表、昨天的列表和 `GET /api/v1/dashboard/overview`：

- `SENSOR-EM-01` 当天是 22℃ / 78% / CO₂ 620 / 基质含水率 68%。`SENSOR-EM-02` 当天是 26℃ / 92% / 980 / 78%。
- 全园均值是这两台（以及当天其他传感器日桶）的算术平均。棚级行（`camera_code` 为空）不计入。不扫 `environment_readings`。
- `SENSOR-EM-YDAY` 的观测时间在昨天，当天列表是空的。`SENSOR-EM-NONE` 当天也是空的。
- 总览的 `envMeanTemperature`、`envMeanHumidity`、`envMeanCo2`、`envMeanSubstrateMoisture` 与日桶算出的四个数相同。

口径：上海自然日的环境日桶。每个传感器取当天 `value`（写入时按观测时间滚入的当日均值；演示里每台当天一条，所以等于这条读数）。全园对温度、湿度、CO₂、基质含水率分别做算术平均，四舍五入到 1 位小数。这与在养蘑菇总数同一类「上海今日、日桶、按主体、全场」口径，环境是平均不是相加。`overview.env` 仍是近 24 小时棚级小时桶均值，值班看板和大屏右侧环境格继续用它，这次不改。

终端第一行是旁注。干净的当天、没有别的传感器环境日桶时：

```text
全园环境参数均值 温度 24℃ · 湿度 85% · CO₂ 800ppm · 基质含水率 73%
```

当天已有别的传感器时，这四个数会按同一口径变化，仍然等于总览接口，也等于下面两个页面上的旁注和卡上的数字。只有这两台时，必须是 24℃、85%、CO₂ 800ppm、基质含水率 73%。

浏览器打开 http://127.0.0.1:43123/login ，账号 `admin`，密码 `Admin@123456`。

## 1. 总览

打开 http://127.0.0.1:43123/ 。「在养蘑菇总数」那一组下面有一块，标题是「全园环境参数均值」。四张卡是「温度」「湿度」「CO₂」「基质含水率」。卡上的数字与下面一行旁注相同。干净当天这一行是「全园环境参数均值 温度 24℃ · 湿度 85% · CO₂ 800ppm · 基质含水率 73%」。

## 2. 基地大屏

打开 http://127.0.0.1:43123/big-screen 。指标条下方同样一块，标题、四张卡和旁注与总览相同。点某一个棚之后，这一块仍是全园均值，不改成单棚最近识别上的温度。

## 3. 对照

`SENSOR-EM-YDAY` 在昨天，不把今天的均值抬高或拉低。`SENSOR-EM-NONE` 当天没有读数。干净的当天、没有别的传感器环境日桶时，总览四张卡和大屏四张卡都是 24℃、85%、800ppm、73%，旁注是「全园环境参数均值 温度 24℃ · 湿度 85% · CO₂ 800ppm · 基质含水率 73%」。再跑一次仍是这个数。

## Mac 截图验收

在 Mac 上 API 已监听 41821、页面已打开时：

1. 跑 `make demo-env-mean`。终端第一行与总览、大屏旁注相同。
2. 截总览 `/`：标题是「全园环境参数均值」，四张卡能读到温度、湿度、CO₂、基质含水率，卡上数字与旁注相同。干净当天旁注是「全园环境参数均值 温度 24℃ · 湿度 85% · CO₂ 800ppm · 基质含水率 73%」。
3. 截基地大屏 `/big-screen`：同样的标题、四张卡和同一句旁注，四个数字与总览一致。

## 验收

- `make demo-env-mean` 在 API 已启动时退出码 0。终端第一行是「全园环境参数均值 温度 N℃ · 湿度 M% · CO₂ Kppm · 基质含水率 P%」。干净当天是 24℃、85%、800ppm、73%。
- 总览 `/` 与基地大屏 `/big-screen` 上的标题、四张卡和旁注与这一行相同。
- 对照传感器 `SENSOR-EM-NONE` 当天是 0 条。`SENSOR-EM-YDAY` 不在今天。`SENSOR-EM-01` 是 22℃ / 78% / 620 / 68%。`SENSOR-EM-02` 是 26℃ / 92% / 980 / 78%。

不改在养蘑菇总数、当日病害总数、今日识别次数、今日抓拍总量的旁注。不改 `/capture-preview`、单棚四数、生长增量、病害趋势、环境 24 小时。不改 `overview.env`。不改接入观测。不改样例文件。不画异常环境点位。

本机若没有 Docker，或 API 没在 41821 监听，命令不会对接口实发。Mac 上再跑 `make demo-env-mean`，并按上面的地址截图。
