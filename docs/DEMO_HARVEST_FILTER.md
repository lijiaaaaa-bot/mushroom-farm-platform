# 按棚区和时间筛选采摘记录

先把数据库和前后端跑起来（已经在跑就跳过）。三个终端：

```bash
make up && make migrate
make api
make web
```

API 监听 http://127.0.0.1:41821 。页面是 http://127.0.0.1:43123 。

在仓库根目录：

```bash
make demo-harvest-filter
```

命令读取 `packages/contracts/fixtures/recognition.demo-one.json`，写两次，样例文件不改。

1. 棚区 S01、摄像头 `CAM-HF-S01`。识别时间是当前时刻前 3 小时。成熟数 5、蘑菇数 12，仍用样例。
2. 棚区 S02、摄像头 `CAM-HF-S02`。识别时间是当前时刻。成熟数 9、蘑菇数 17。只改这次请求，不改样例文件。

两次的病害数量都是样例里的 1，病害等级是 1，低于种子规则「病害数量一般」的 5 和「病害等级一般」的 2，所以不新开告警。温度仍是 22.5℃。

`GET /api/v1/harvest/daily` 在 `from`、`to` 都有时，按识别时间比较，含两端。窗口里每个摄像头仍只留最新一条。不传 `from`、`to` 时，仍按上海日期 `date` 查那一天。`shedCode` 空白表示全部棚区。只传开始或结束、时间无效、或开始晚于结束时，接口返回 400，页面写「时间筛选无效」，不保留上一次的表。没有命中的行时写「没有符合条件的采摘记录。」。

宽窗口是当前时刻前 4 小时到后 1 分钟。窄窗口是当前时刻前 30 分钟到后 1 分钟。

然后读三份接口：

- 宽窗口、不传棚区：有 `CAM-HF-S01` 和 `CAM-HF-S02`。条数不少于 2。
- 同一宽窗口、`shedCode=S01`：有 `CAM-HF-S01`，没有 `CAM-HF-S02`，也没有 S02。条数少于宽窗口，成熟数汇总也更小。
- 窄窗口、不传棚区：有 `CAM-HF-S02`，没有 `CAM-HF-S01`。条数少于宽窗口，成熟数汇总也更小。

终端打印这三行地址：

```text
全部棚区: http://127.0.0.1:43123/harvest?from=<宽窗口开始>&to=<宽窗口结束>
棚区 S01: http://127.0.0.1:43123/harvest?from=<同一开始>&to=<同一结束>&shedCode=S01
窄窗口: http://127.0.0.1:43123/harvest?from=<窄窗口开始>&to=<同一结束>
```

浏览器打开 http://127.0.0.1:43123/login ，账号 `admin`，密码 `Admin@123456`。

## 1. 全部棚区

打开终端里的「全部棚区」。页面向下找到「当日采摘记录」。这一行写出「棚区 全部」，并写出「时间 … 至 …」和「共 N 条」。N 至少是 2，并且大于下面两张的条数。

表里同时有：

| 棚区 | 摄像头 | 成熟 | 总数 |
| --- | --- | --- | --- |
| S01 | CAM-HF-S01 | 5 | 12 |
| S02 | CAM-HF-S02 | 9 | 17 |

时间以终端打印的时刻为准，页面按上海时间显示到分钟。S01 比 S02 早大约 3 小时。

## 2. 只要 S01

打开终端里的「棚区 S01」。棚区输入是 `S01`。范围文字是「棚区 S01」，时间起止和第一节相同。「共 N 条」的 N 比第一节少。

表里有 `CAM-HF-S01`，成熟数 5，总数 12。没有 `CAM-HF-S02`，也没有棚区 S02。

和第一节并排时，一份有两棚，一份只有 S01，行数不一样。

## 3. 窄窗口

打开终端里的「窄窗口」。棚区是「全部」。开始时间比第一节晚，结束时间和第一节相同。「共 N 条」的 N 比第一节少。

表里有 `CAM-HF-S02`，成熟数 9，总数 17。没有 `CAM-HF-S01`。

和第一节并排时，窄窗口少了 3 小时前那一行。

也可以在 `/harvest` 自己填。棚区留空是全部，填 `S01` 后再点「查询」。开始时间和结束时间都要填。只填一边，或开始晚于结束，页面写「时间筛选无效」，不把空表当成没有记录。点「清除棚区与时间」后不再按棚区和起止时间过滤，日期和摄像头还在。

点某一行的「打开」再点「返回采摘清单」，棚区和起止时间还在。

## 验收

- `make demo-harvest-filter` 在 API 已启动时退出码 0，并打印全部棚区、棚区 S01、窄窗口三个地址。
- 全部棚区截图里至少有 S01 和 S02 两行，能读到棚区、摄像头、成熟数、总数，以及「共 N 条」。
- 棚区 S01 截图里有 `CAM-HF-S01`，没有 `CAM-HF-S02`，条数更少。
- 窄窗口截图里有 `CAM-HF-S02`，没有 `CAM-HF-S01`，条数更少。

`make demo-harvest-list`、`make demo-disease-list`、`make demo-report-xlsx` 与 `make demo-alert-by-device` 不改。样例文件不改。不导出 xlsx。不生成采摘任务，不排班。
