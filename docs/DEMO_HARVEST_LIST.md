# 采摘记录可查可见

先把数据库和前后端跑起来（已经在跑就跳过）。三个终端：

```bash
make up && make migrate
make api
make web
```

API 监听 http://127.0.0.1:41821 。页面是 http://127.0.0.1:43123 。

在仓库根目录：

```bash
make demo-harvest-list
```

命令读取 `packages/contracts/fixtures/recognition.demo-one.json`，只改本次请求：摄像头 `CAM-HAR-01`，棚区 `S01`，识别时间改成当前时刻，幂等键改成 `demo-harvest-list-<毫秒>`。样例文件里的 `CAM-DEMO-01`、成熟数 5、蘑菇数 12、菌盖直径 3.2 / 4.8 / 6.1 不改。温度仍是 22.5℃。病害数量 1 低于种子规则「病害数量一般」的 5，病害等级 1 低于「病害等级一般」的 2，所以这条识别不新开告警。

然后读三份接口：

- `GET /api/v1/harvest/daily?date=<上海日期>&cameraCode=CAM-HAR-01` 里有这一条。时间、棚区 S01、摄像头 `CAM-HAR-01`、成熟数 5、蘑菇数 12 都在。
- `GET /api/v1/harvest/daily/:id` 与列表这一行一致，菌盖直径是 4.7。
- `GET /api/v1/harvest/daily?date=<同一上海日期>&cameraCode=CAM-HAR-NONE` 的 `items` 是空的，成熟数和蘑菇数汇总为 0。

抓拍要能从对象存储读回，并且字节与样例 JPEG 一致。对象存储没起来时命令失败。

终端打印这三行地址：

```text
采摘列表: http://127.0.0.1:43123/harvest?date=<上海日期>&cameraCode=CAM-HAR-01
采摘详情: http://127.0.0.1:43123/harvest/<id>?date=<上海日期>&cameraCode=CAM-HAR-01
对照列表: http://127.0.0.1:43123/harvest?date=<上海日期>&cameraCode=CAM-HAR-NONE
```

浏览器打开 http://127.0.0.1:43123/login ，账号 `admin`，密码 `Admin@123456`。

## 1. 列表有行

打开终端里的「采摘列表」。页面向下找到「当日采摘记录」。表里至少一行：

| 棚区 | 摄像头 | 成熟 | 总数 | 最近识别 |
| --- | --- | --- | --- | --- |
| S01 | CAM-HAR-01 | 5 | 12 | 上海时间 |

时间以终端打印的时刻为准，页面按上海时间显示到分钟。这一行有「打开」。

没有这一行，或写成「没有符合条件的采摘记录。」，都算没对上。

## 2. 详情能展开字段

点这一行的「打开」，或直接打开终端里的「采摘详情」。顶栏是「采摘详情」。这一页要能读到：

| 标签 | 值 |
| --- | --- |
| 时间 | 与列表同一时刻 |
| 棚区 | S01 |
| 摄像头 | CAM-HAR-01 |
| 成熟数 | 5 |
| 蘑菇数 | 12 |
| 菌盖直径 | 4.7 |

没有直径时这一页写「—」。本命令要求是 4.7。

点「返回采摘清单」回到刚才的列表，日期和摄像头筛选还在。

## 3. 对照

打开终端里的「对照列表」。摄像头是 `CAM-HAR-NONE`。页面写「没有符合条件的采摘记录。」，表里没有 `CAM-HAR-01`。

和第一节的列表并排时，一份有行，一份没有。

也可以在 `/harvest` 自己填：日期用终端里的上海日期，摄像头 `CAM-HAR-01`，点「查询」。改成 `CAM-HAR-NONE` 后再查，应看到空列表。日期不是 `YYYY-MM-DD` 时，页面写「日期无效」，不把空表当成没有记录。

## 验收

- `make demo-harvest-list` 在 API 已启动时退出码 0，并打印列表、详情、对照三个地址。
- 列表截图里至少有一行，能读到棚区、摄像头、成熟数、蘑菇数。
- 详情截图里上述字段都在，菌盖直径是 4.7。
- 对照截图是空列表，文案是「没有符合条件的采摘记录。」

`make demo-disease-list`、`make demo-report-xlsx` 与 `make demo-alert-by-device` 不改。样例文件不改。不导出 xlsx。不生成采摘任务，不排班。
