# 成熟菇数量阈值与采摘提醒

先把数据库和前后端跑起来（已经在跑就跳过）。三个终端：

```bash
make up && make migrate
make api
make web
```

API 监听 http://127.0.0.1:41821 。页面是 http://127.0.0.1:43123 。

在仓库根目录：

```bash
make demo-mature-pick-threshold
```

命令用管理员账号读写已有的阈值规则，不另建一套配置。没有名为「采摘提醒」、指标为成熟菇数量、棚区为空（全场）的规则时，`POST /api/v1/alert-rules` 新建一条：级别提示，窗口 720 分钟。然后 `PATCH /api/v1/alert-rules/:id`，把阈值写成 8，并保持启用。同一指标上其他已启用的规则会改成停用，避免总览改读另一条更小的阈值。种子规则不改，包括「成熟占比一般」仍是 0.6。

然后读取 `packages/contracts/fixtures/recognition.demo-one.json`，只作报文底稿。样例文件不改。写入当天两条识别，识别时间都在运行时刻的上海自然日里：

| 棚区 | 摄像头 | 蘑菇数 | 成熟 | 病害数量 |
| --- | --- | --- | --- | --- |
| `S01` | `CAM-MPT-01` | 20 | 8 | 0 |
| `S02` | `CAM-MPT-ZERO` | 0 | 0 | 0 |

病害等级 0。温度 22.5℃，湿度 88%，CO₂ 900，基质含水率 70%。成熟占比 8/20，低于种子规则「成熟占比一般」的 0.6。病害数量低于「病害数量一般」的 5。病害等级低于「病害等级一般」的 2。幂等键是 `demo-mature-pick-threshold-<摄像头>-<上海日>`。同一上海日再跑不另建一行。样例里的 `CAM-DEMO-01`、蘑菇数 12、病害数量 1、AI抓拍图不改。本次请求不带抓拍。这条规则不按单条识别新开告警，`CAM-MPT-01` 与 `CAM-MPT-ZERO` 的待确认列表里没有指标为成熟菇数量的告警行。

然后读 `GET /api/v1/dashboard/overview`。阈值是全场规则上的整数。当前成熟是当日各棚摄像头日桶最新成熟数相加，与 `liveMatureTotal` 同一口径。当前成熟 ≥ 8 时提醒生效。

终端第一行是旁注。干净的当天、没有别的成熟日桶时：

```text
采摘提醒 成熟≥8 当前8
```

当天已有别的摄像头时，当前数不小于 8，旁注变成「采摘提醒 成熟≥8 当前N」，仍然等于总览接口，也等于总览页上的横幅。

浏览器打开 http://127.0.0.1:43123/login ，账号 `admin`，密码 `Admin@123456`。

## 1. 总览

打开 http://127.0.0.1:43123/ 。在养三张卡下面有一块「采摘提醒」。成熟菇数量阈值的输入框是 8。配置旁注是「成熟菇数量阈值 8 · 全场 · 当前成熟 N」。当前成熟达到 8 时，下面有一条横幅，文案与终端第一行相同。干净当天是「采摘提醒 成熟≥8 当前8」。超管和生产管理员可以改输入框并点「保存」，保存后重新读总览。查看角色看得到阈值，没有「保存」。

`/alert-rules` 里同一条规则的指标是「成熟菇数量」，阈值是 8，棚区是全场，启用是「是」。总览这一块就是改这条规则，不另存一份阈值。

## 2. 对照

`CAM-MPT-ZERO` 成熟是 0，不把全场抬高。`CAM-MPT-NONE` 当天没有识别。干净的当天、没有别的成熟日桶时，横幅是「采摘提醒 成熟≥8 当前8」。再跑一次仍是这个旁注。

## Mac 截图验收

在 Mac 上 API 已监听 41821、页面已打开时：

1. 跑 `make demo-mature-pick-threshold`。终端第一行与总览横幅相同。
2. 截总览 `/`：标题是「采摘提醒」，阈值输入框能读到 8，横幅能读到「采摘提醒 成熟≥8 当前N」。干净当天 N 是 8。
3. 配置旁注能读到「成熟菇数量阈值 8 · 全场 · 当前成熟 N」，N 与横幅里的当前数相同。

## 验收

- `make demo-mature-pick-threshold` 在 API 已启动时退出码 0。终端第一行是「采摘提醒 成熟≥8 当前N」。干净当天 N 是 8。当前成熟不小于 8。
- 总览 `/` 上的阈值、配置旁注和横幅与这一行相同。
- `GET /api/v1/dashboard/overview` 的 `maturePickThreshold` 是 8，`maturePickActive` 是 true，`maturePickMatureCount` 是 N，`maturePickNote` 是「采摘提醒 成熟≥8 当前N」，`maturePickShedCode` 是空。
- 对照摄像头 `CAM-MPT-NONE` 当天是 0 条。`CAM-MPT-ZERO` 蘑菇 0、成熟 0。`CAM-MPT-01` 蘑菇 20、成熟 8。
- 这两台摄像头上没有指标为成熟菇数量的待确认告警。

不改在养蘑菇总数、当日病害总数、今日识别次数、今日抓拍总量、全园环境参数均值、异常环境点位数、全局设备在线的旁注。不改基地大屏。不改接入观测。不改样例文件。不画点位分布。不改病害阈值、环境阈值，也不发企微。

本机若没有 Docker，或 API 没在 41821 监听，命令不会对接口实发。Mac 上再跑 `make demo-mature-pick-threshold`，并按上面的地址截图。
