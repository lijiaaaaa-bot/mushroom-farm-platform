# 报表按棚区筛选后预览、导出、打印

先把数据库和前后端跑起来（已经在跑就跳过）。三个终端：

```bash
make up && make migrate
make api
make web
```

API 监听 http://127.0.0.1:41821 。页面是 http://127.0.0.1:43123 。

在仓库根目录播种并核对：

```bash
make demo-report-browse
```

命令读取 `packages/contracts/fixtures/recognition.demo-one.json`，写两次，样例文件里的 `CAM-DEMO-01` 不改。请求头是 `X-Ingest-Token: dev-ingest-token`。识别时间是当前时刻。同一上海日的幂等键已在则不另建一行。

1. 棚区 S01、摄像头 `CAM-RB-S01`。蘑菇数量 11，成熟数量 4。
2. 棚区 S02、摄像头 `CAM-RB-S02`。蘑菇数量 17，成熟数量 9。

病害数量、病害等级、温度、湿度和 CO₂ 仍用样例。不确认、不关闭告警。

识别写入当日日桶后，命令用 `admin` / `Admin@123456` 登录，再读两份园区生长预览（粒度日，从和到都是上海今天）：

- 不带 `shedCode`：有 S01，也有 S02。蘑菇数量分别至少 11 和 17，成熟数量分别至少 4 和 9。当天还有别的棚时，行更多。
- `shedCode=S02`：只有 S02，没有 S01。行数少于全部棚。

然后 `GET /api/v1/reports/export.xlsx` 带上同一组 S02 参数。响应是 xlsx，文件名 `export.xlsx`，工作表名称是「园区生长」，表里有 S02，没有 S01。缺行、全部棚不多于只看 S02，或文件不是工作簿时，命令失败。

终端打印三个地址：

```text
预览（全部棚）: http://127.0.0.1:43123/reports?kind=growth&grain=day&from=YYYY-MM-DD&to=YYYY-MM-DD
预览（S02）: http://127.0.0.1:43123/reports?kind=growth&grain=day&from=YYYY-MM-DD&to=YYYY-MM-DD&shedCode=S02
导出: http://127.0.0.1:41821/api/v1/reports/export.xlsx?kind=growth&grain=day&from=YYYY-MM-DD&to=YYYY-MM-DD&shedCode=S02
```

浏览器打开 http://127.0.0.1:43123/login ，账号 `admin`，密码 `Admin@123456`。再打开终端里的两个预览地址。地址带 `kind=growth` 时，页面自己请求预览，不用先点「预览」。

预览区写出「棚区 全部 · 共 N 条」或「棚区 S02 · 共 M 条」。N 大于 M。表标题是「园区生长」。没有行时页面写「该筛选下没有数据。」，「打印」是灰色，这不算通过。

`导出` 那一行是接口地址。命令已经用登录令牌下载并核对工作簿。页面上不要把这一行贴进未登录的地址栏。在已经出表的预览页点「导出」。

## 1. 全部棚

打开「预览（全部棚）」。棚区输入是空的。范围文字是「棚区 全部 · 共 N 条」。N 至少是 2。

表里同时有棚区 S01 和 S02。S01 的蘑菇数量至少 11，成熟数量至少 4。S02 的蘑菇数量至少 17，成熟数量至少 9。当天库里还有别的棚时，那些行也在，N 更大。

## 2. 只要 S02

打开「预览（S02）」。棚区输入是 `S02`。范围文字是「棚区 S02 · 共 M 条」。M 比上一节的 N 少。

表里有 S02，没有 S01。和第一节并排时，一份有两棚或更多，一份只有 S02。

## 3. 导出

留在「预览（S02）」这一页，点「导出」。页面写出「已开始下载 growth.xlsx」，浏览器同时下载这个文件。用表格软件打开，工作表是「园区生长」，里面有 S02，没有 S01。空文件时页面写「该报表没有可导出的数据。」，这不算通过。

## 4. 打印

同一页预览已经有行时，「打印」可点，不是灰色。点下去调用 `window.print()`，浏览器弹出打印对话框。截对话框，或只截可点的「打印」按钮和上面的表。没有行时按钮是灰色，点下去不会打印。没有单独的打印样式表。

## Mac 截图

登录后再截。至少四张：

1. 全部棚预览有行。地址栏是终端打印的「预览（全部棚）」。画面里能读到「园区生长」、「棚区 全部 · 共 N 条」，以及棚区 S01 和 S02。
2. 只看 S02 的预览行更少。地址栏是「预览（S02）」。画面里能读到「棚区 S02 · 共 M 条」和 S02，没有 S01。M 小于上一张的 N。
3. 导出有反馈。在只看 S02 的页面点「导出」之后，页面上有「已开始下载 growth.xlsx」。
4. 打印可点。有行时「打印」不是灰色；点下去则留下打印对话框。两处都有就留对话框那一张。

`make demo-report-xlsx` 仍只发 `CAM-RPT-01`。本命令不改那条演示，不改样例文件，不改接入观测。
