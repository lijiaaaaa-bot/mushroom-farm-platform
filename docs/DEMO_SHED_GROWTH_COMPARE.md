# 棚间生长横向对比

先把数据库和前后端跑起来（已经在跑就跳过）。三个终端：

```bash
make up && make migrate
make api
make web
```

API 监听 http://127.0.0.1:41821 。页面是 http://127.0.0.1:43123 。

在仓库根目录：

```bash
make demo-shed-growth-compare
```

命令读取 `packages/contracts/fixtures/recognition.demo-shed-growth-compare.json`，写入两台摄像头的三天识别。数量以样例为准：

| 上海日 | S01 `CAM-SG-S01` | S02 `CAM-SG-S02` |
| --- | --- | --- |
| 前 5 日 | 蘑菇 8，成熟 2 | 蘑菇 3，成熟 1 |
| 前 2 日 | 蘑菇 14，成熟 5 | 蘑菇 5，成熟 2 |
| 当天 | 蘑菇 21，成熟 8 | 蘑菇 8，成熟 3 |

同一天 S01 的蘑菇数高于 S02。当天是 21 和 8。菌盖直径当天也是 S01 更大。识别时间按运行时刻往前推，幂等键是 `demo-shed-growth-compare-<摄像头>-<上海日>`。同一天再跑沿用这一行，不另建，样本数不加。样例文件不改。`recognition.demo-one.json` 里的 `CAM-DEMO-01` 不改。`recognition.demo-growth-trend.json` 里的 `CAM-GT-01` 不改。

病害数量 0，病害等级 0，温度 22.5℃，湿度 88%，CO₂ 900，基质含水率 70%。成熟占比低于种子规则「成熟占比一般」的 0.6，所以这六条不因成熟占比新开告警。对象存储没起来时，第一次写入失败。

然后读两份接口，都不带 `shedCode`：

- `GET /api/v1/growth-trends?days=7` 的天数是 7。`CAM-SG-S01` 与 `CAM-SG-S02` 都在，并且含上面三天。当天蘑菇数是 21 和 8，S01 高于 S02。
- `GET /api/v1/growth-trends?days=30` 同样两台、三天都在，当天仍是 21 和 8。

棚汇总是各摄像头当日最新蘑菇数相加。棚里只有这两台时，当天棚汇总就是 21 和 8。同一棚还有别的摄像头时，棚汇总会更大，表里这两台仍是 21 和 8。

终端打印这两行地址：

```text
打开: http://127.0.0.1:43123/growth-compare?days=7
三十日: http://127.0.0.1:43123/growth-compare?days=30
```

浏览器打开 http://127.0.0.1:43123/login ，账号 `admin`，密码 `Admin@123456`。侧栏「棚间对比」也进这一页。

## 1. 两棚同屏

打开终端里的「打开」。页顶能读到：

| 位置 | 值 |
| --- | --- |
| 文字 | 棚间对比 · 7 天 |
| 按钮 | 「7 天」是当前选中 |
| 当日对照 | 两张卡并排，棚区是 S01 和 S02 |

S01 那张卡的大号数字是蘑菇数。棚里只有 `CAM-SG-S01` 时，这个数是 21。卡上还有一行 `CAM-SG-S01 蘑菇 21 成熟 8`。S02 那张卡对应是 8 和 `CAM-SG-S02 蘑菇 8 成熟 3`。卡下面一行写着「当日 S01 蘑菇 21 · S02 蘑菇 8」。两张卡不用切换棚区下拉。

页面向下有三块曲线：蘑菇数量、成熟数量、菌盖直径均值。每块图例都是 S01 和 S02 两条。同一天 S01 的点高于 S02。不要停在「没有日聚合，未绘制曲线。」也不要停在「至少要两个棚才能对照。」

再往下是表。同一天相邻两行能读到 S01 与 S02。对象列有「棚汇总」，也有 `CAM-SG-S01` 和 `CAM-SG-S02`。当天 `CAM-SG-S01` 的蘑菇数量是 21，`CAM-SG-S02` 是 8。

## 2. 三十日仍能看到这两棚

打开终端里的「三十日」，或在同一页点「30 天」。文字变成「棚间对比 · 30 天」。当日对照仍是两张卡，当天蘑菇数仍是 21 和 8。点「7 天」回到上一节。

## 验收

- `make demo-shed-growth-compare` 在 API 已启动时退出码 0，并打印 7 日和 30 日两个地址。
- 7 日截图同一屏能读到 S01 和 S02，不用切换棚区。蘑菇数肉眼能看出差距（21 与 8）。成熟数和菌盖也能读到。
- 30 日截图仍是这两棚、当天仍是 21 和 8。

`make demo-growth-trend` 不改。不改接入观测。不改产量预测算法。
