# 超管在系统参数页改一项并看到前后

先把数据库和前后端跑起来（已经在跑就跳过）。三个终端：

```bash
make up && make migrate
make api
make web
```

API 监听 http://127.0.0.1:41821 。页面是 http://127.0.0.1:43123 。

## 1. 改告警未读轮询

在仓库根目录：

```bash
make demo-sys-params
```

命令用种子超管 `admin` / `Admin@123456` 登录。

先读 `GET /api/v1/system-params`。没人改过时，图片保留是 30 天，时序保留是 90 天，告警未读轮询是 15 秒。

然后 `PATCH /api/v1/system-params`，只送 `alertUnreadPollSeconds`。当前是 15 就改成 45；当前已经是 45 就改回 15。再读一次：

| 检查 | 结果 |
|------|------|
| 告警未读轮询 | 和改之前不同 |
| 前后文案 | `告警未读轮询：15 秒 → 45 秒`，或反向 |
| 图片保留 | 与改之前相同 |
| 时序保留 | 与改之前相同 |
| 修改人 | `admin` |

接着用查看 `viewer` / `Viewer@123456` 登录。`GET /api/v1/system-params` 和 `PATCH /api/v1/system-params` 都是 403。不改这个账号的密码。生产管理员、棚区负责人调用同样是 403。

不发识别，不发心跳，不改告警，不改用户。不改接入观测。不改图片保留和时序保留。

终端打印图片保留、时序保留、那句前后文案和系统参数页地址。

## 2. 在页面上看前后

浏览器打开 http://127.0.0.1:43123/login 。

用 `admin` / `Admin@123456` 登录。侧栏在「数据备份」后面有「系统参数」。打开 http://127.0.0.1:43123/system-params 。

三项都写出「当前」：图片保留、时序保留、告警未读轮询。数字与终端里改完之后的一致。告警未读轮询是 15 秒或 45 秒。

把告警未读轮询改成另一个数（15 或 45），点「保存」。按钮在请求期间写「保存中…」。完成后这一行被描出，页面写「告警未读轮询：15 秒 → 45 秒」或反向。这一行的「当前」换成箭头右边的秒数。图片保留和时序保留的「当前」不动。

退出后用 `viewer` / `Viewer@123456` 登录。侧栏没有「系统参数」。打开 http://127.0.0.1:43123/system-params 会回到总览。

每天 03:00 的清理会读取页面上的图片保留和时序保留。超管顶栏的未读轮询按保存的秒数走。其他角色读不到这个接口，顶栏仍是 15 秒。补传窗口仍是 90 天。心跳超时仍由启动 API 时的 `DEVICE_OFFLINE_AFTER_MS` 决定。

`make demo-backup-run`、`make demo-rbac` 以及其他已有演示命令都不改。
