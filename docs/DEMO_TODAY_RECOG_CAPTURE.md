# 今日识别次数与今日抓拍总量

先把数据库和前后端跑起来（已经在跑就跳过）。三个终端：

```bash
make up && make migrate
make api
make web
```

API 监听 http://127.0.0.1:41821 。页面是 http://127.0.0.1:43123 。

在仓库根目录：

```bash
make demo-today-recog-capture
```

命令读取 `packages/contracts/fixtures/recognition.demo-one.json`，只作报文底稿。样例文件不改。写入摄像头 `CAM-TRC-01`、棚区 `S01` 的三条识别，识别时间都在运行时刻的上海自然日里：

| 条 | 蘑菇数 | 成熟 | 病害 | 抓拍 |
| --- | --- | --- | --- | --- |
| 有抓拍 | 8 | 2 | 1 | 样例 JPEG，对象键可打开 |
| 有抓拍 | 11 | 4 | 1 | 样例 JPEG，对象键可打开 |
| 无抓拍 | 6 | 1 | 0 | 没有对象键，也没有抓拍 URL |

病害等级 1。温度 22.5℃，湿度 88%，CO₂ 900，基质含水率 70%。成熟占比低于种子规则「成熟占比一般」的 0.6。病害数量低于「病害数量一般」的 5。病害等级低于「病害等级一般」的 2。幂等键是 `demo-today-recog-capture-<槽位>-<上海日>`。同一上海日再跑不另建一行。样例里的 `CAM-DEMO-01`、蘑菇数 12、病害数量 1、AI抓拍图不改。对象存储没起来时，两条带图的写入失败。

然后读当天的识别列表和 `GET /api/v1/dashboard/overview`：

- `CAM-TRC-01` 当天有蘑菇数 8、11、6。8 和 11 的 `snapshotObjectKey` 有值，`GET /api/v1/ingest/recognitions/:id/snapshot` 读回的字节与样例 JPEG 一致。蘑菇数 6 没有对象键，也没有抓拍 URL。
- 同一天 `cameraCode=CAM-TRC-NONE` 的列表是空的。终端写「对照 CAM-TRC-NONE: 今日识别 0 · 今日抓拍 0」。
- 总览的 `todayRecognitionCount` 是今日识别次数，`todayCaptureCount` 是今日抓拍总量。今日按识别时间 `recognizedAt` 的上海自然日。识别次数是各棚当日日桶 `sample_count` 相加（成功入库且非重复各加一）。抓拍总量是同一日桶的 `capture_count`，只计带抓拍对象键或抓拍 URL 的识别。没有图的那一条计入识别次数，不计入抓拍总量。两数都只加棚级行，不把摄像头行再加一遍。抓拍总量不会大于识别次数。

终端第一行是旁注，例如干净的当天、没有别的识别时：

```text
今日识别次数 3 · 今日抓拍总量 2
```

当天已有别的识别时，这两数会更大，仍然等于总览接口，也等于下面两个页面上的旁注。

浏览器打开 http://127.0.0.1:43123/login ，账号 `admin`，密码 `Admin@123456`。

## 1. 总览

打开 http://127.0.0.1:43123/ 。页顶两张卡是「今日识别次数」和「今日抓拍总量」。下面一行旁注与终端第一行相同，例如「今日识别次数 3 · 今日抓拍总量 2」。

## 2. 基地大屏

打开 http://127.0.0.1:43123/big-screen 。指标条里同样有「今日识别次数」和「今日抓拍总量」，数字与总览两卡相同。指标条下方同一句旁注。

## 3. 对照

`CAM-TRC-NONE` 当天没有识别。蘑菇数 6 的那一条没有抓拍。总览两卡在没有别的当日识别时是 3 和 2，不是 3 和 3。

值班看板分棚上的「今日识别」仍是当天棚级日桶的 `sampleCount`，本命令不改那一页。

## 验收

- `make demo-today-recog-capture` 在 API 已启动、对象存储可写时退出码 0。终端第一行是「今日识别次数 N · 今日抓拍总量 M」，并且 M 不大于 N。
- 总览 `/` 与基地大屏 `/big-screen` 上的两卡和旁注与这一行相同。
- 干净的当天、没有别的识别时，这一行是「今日识别次数 3 · 今日抓拍总量 2」。再跑一次仍是这两数。
- 对照摄像头 `CAM-TRC-NONE` 当天是 0 条。蘑菇数 6 没有抓拍对象键。

不改 `/capture-preview`、`/recognitions` 列表、单棚四数、生长增量、病害趋势、环境 24 小时、病害高发、成熟率。不改接入观测。不改样例文件。

本机若没有 Docker，或 API 没在 41821 监听，命令不会对接口实发。Mac 上再跑 `make demo-today-recog-capture`，并按终端里的总览和大屏地址截图。
