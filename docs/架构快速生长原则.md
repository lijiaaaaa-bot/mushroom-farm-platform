## 1. 一句话

**Day-1 立全骨架与稳定接缝；功能按日向外长，禁止后期螺栓式硬塞、禁止旁路双实现。**

交付模式为 coding agent 加速：日历以日尺度推进，不以「6–8 周堆功能再补架构」为默认路径。

---

## 2. 反幻觉墙：硬代码，不是文档

**文档服务人；AI 只能在代码门禁内工作。** 统一入口 → 向内筑墙：所有变更从单一 `Makefile` 入口进入，经 smoke、contracts、Zod、模块边界 lint 与 CI 检查；红灯不得合并。

具体墙：

- `packages/contracts`：类型化契约包；前端消费共享类型，禁止重复定义。
- 运行时校验：Zod 等边界校验拒绝未知字段，不把脏输入带入核心模块。
- 模块边界 lint：限制跨模块依赖与旁路调用。
- golden fixtures：用固定样例锁住 DTO、事件与关键输出。
- 单一 Make 入口 + smoke CI：本地与 CI 执行同一组检查。

## 3. Day-0/1 必须存在（薄实现亦可）

| 项 | 最低标准 |
|----|----------|
| Monorepo | `apps/api`、`apps/web`、`packages/contracts`（共享类型） |
| docker 依赖 | PG / Redis / MinIO / Mosquitto 可 `up` + 健康检查 |
| Nest 模块桩 | Ingest / Alert / Rbac / Device / Harvest / Report **已注册接线** |
| Vue 应用壳 | 布局、路由占位、登录壳、导航；大屏为清亮农作物监控风格 |
| 配置 + seed | `.env` 模板；四角色 + 样例棚/设备/用户 |
| CI-ish 冒烟 | typecheck/lint + compose 冒烟脚本可绿 |

> 功能可空，**模块边界与路由契约不可缺。**

---

## 4. 尽早冻结的接缝（Seams）

变更这些接缝必须走版本号 / 适配层，禁止静默改形状：

| 接缝 | 冻结内容【假设】 |
|------|------------------|
| **Ingest DTO** | 识别/环境/心跳字段与去重键（见 SRS §7–§8） |
| **告警状态机** | 产生 → 通知 → 确认/认领 → 处置 → 关闭/误报；状态枚举与审计事件 |
| **RBAC** | 四角色 + `UserShedScope` 服务端强制；菜单/API 双控约定 |
| **MinIO key 布局** | `shed/{shedId}/{yyyy-MM-dd}/{cameraId}/{HHmmss}.jpg`（或等价；一经采用不随意改） |
| **MQTT Topic** | `mushroom/{siteId}/shed/{shedId}/...` 命名树；QoS 约定 |

厂商差异进 **协议适配器 → 统一 DTO**，不污染核心管道。

---

## 6. 生长规则（防结构债）

1. **新能力只进既有模块**，不另起平行服务/平行表「临时方案」。  
2. **共享 DTO / 枚举以 `packages/contracts` 为唯一真相源**；前端只消费共享类型，agent 产出须对齐契约测试。  
3. **UI 屏在壳内加路由**，不改导航信息架构除非产品明示。  
4. **先契约测试/冒烟，再填肉**；接缝破坏 = 红灯，不得合并。  
5. 架构从 Day-1 基地**向外扩展**；若某功能迫使改接缝，先改契约文档再改代码。
